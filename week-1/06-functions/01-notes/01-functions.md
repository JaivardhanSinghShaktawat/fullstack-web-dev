## What are functions ?

- Function is a reusable piece of code.
- It abstract out logic in your program.
- It takes arguments as an input.
- Return a value as an output.
- You can think of them as an independent program that is supposed to do something given an input.
- Functions can take other functions as input.
- A function will run only if it is called.

```js
// Write a function to find sum of a and b.

// defining the function.
function findSum(a, b) {
  return a + b;
}
```
