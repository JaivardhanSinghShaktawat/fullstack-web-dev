# Conditional Statements

## If Else Statements

- if else are used to run certain part/section of the codebases based on the condition.

- if the condition inside the if evaluated to true than if block is executed otherwise else block is executed.

```js
let firstName = "hello";
let age = 20;
let isMarried = false;

if (isMarried === true) {
  console.log(firstName + " is married");
} else {
  console.log(firstName + " is not married");
}
```
