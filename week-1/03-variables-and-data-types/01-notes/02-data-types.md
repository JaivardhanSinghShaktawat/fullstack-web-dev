# Data Types

## What are data types ?

- Data types means different type of data like integer, string, boolean etc.

1. number : it represent integers.

2. string : it represent text.

3. boolean : it is a logical value that is true or false.

**Note :** name is a reserved keyword in JavaScript.Don't use it to define variables.

```js
let firstName = "hello world"; // string type
let age = 20; // number type
let isMarried = false; // boolean type

// combining/concatinating the strings using plus operator.
console.log("This person name is " + firstName + " and their age is " + age);
```
