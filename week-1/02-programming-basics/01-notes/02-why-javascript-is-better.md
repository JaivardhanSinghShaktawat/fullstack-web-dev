# Why JavaScript Is Better ?

## Why JavaScript is better than other languages in some use cases ?

- Each and every programming language has some usecases.

- JavaScript was mainly created for web development.

- Browsers can only understands HTML,CSS and JavaScript (not technically true).We can even run C++,Rust in browser.

- With the help of NodeJs , JavaScript can also be used for Backend Development.

- Browsers interprets HTML,CSS and JavaScript and renders it.

- JavaScript is not good when it comes to speed or concurrency.

## Why no new language is used other than javascript for web dev ?

1. current websites will break.
2. browsers will be re-written according to the new language.
