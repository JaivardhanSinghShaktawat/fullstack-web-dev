## What is RAM ?

- A computer has RAM, processor , hard disk and GPU.

- RAM stands for random access memory.

- Programs runs inside the RAM.

- Applications like VLC,Zoom,browsers or VSCode runs inside RAM and are stored in SSD or HDD.

## What is SSD ?

- SSD is a storage device where programs and files are stored.

## What goes inside the RAM ?

- Whenever we run a program, it's 0's and 1's that goes inside the RAM.

- Computer only understands machine level language.

## Why we need programming languages ?

- Developers are dumb and they can't write code in machine level language.It's hard to write code in machine level language.

- Languages are used to write applications.

- Developers write high level code in these languages.

- Every language has a compiler which converts the developer code into 0's and 1's.

## Why there are so many programming languages ?

- There are many programming languages because each programming is created to solve some problem or to optimize something.

- In the end, every programming language is converting high level language into 0's and 1's.

- Ex : HTML,CSS,JavaScript is mainly created for web development.

## Compiler

- Compilers convert high level developer friendly code into 0's and 1's.

- The C++ compiler is called g++.

**High level code -> compiler -> machine level code**
