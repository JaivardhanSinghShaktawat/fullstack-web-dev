# HTML

## What is HTML ?

- HTML stands for HyperText Markup Language.
- It defines the structure of the web page.

## What are Tags ?

- Tags are used to structure the content of the document.

- List of tags that are enough to know.

```
<html> : it is the root html element.It represent the whole html page.It contains head and body element.
<head> : it provides meta data about the web page like title , description etc.
<title> : it represents the title of the web page.It is visible on the tab of the browser.
<body> : it contains the content that is visible on the web page.
<div> : it stands for one division of your page.It is used to divide or separate the content.
<span> : it is used to style a specific part of the html element.It is an inline element.
<h1> .. <h6> : it is used to give heading to some section.
<p> : it represent text content like paragraph.
<img> : it is used to add images to the html document.
<a> : it is used to create hyperlink.It is used to connect web pages together.
<input> : it is used to create input boxes.
<button> : it represents a button.
<b> : it makes the font bold.
</i> : it makes the font slanted or italic.
<center> : it centers the content horizontally.It is deprecated and not used much.
```

## How to open HTML files ?

- HTML files by default open in our browsers.

## Need of a tag

- it gives a better structure to the web page.

## Note

- Even if we don't define a proper HTML structure than browser automatically defines the basic HTML structure.

## Div vs span

- div takes full space.
- span takes only the required space.
- div is block element and span is inline element.

## What are attributes ?

- Attributes are key value pairs that adds more functionality to the html elements.

- Each tag can have multiple attributes.

- Each attribute add some functionaltiy to the html element.

- Ex : src , href , onclick , id , target etc.

```html
<img src="a.png" />
<a href="google.com">Google</a>
<button onclick="" type="button" />
<input id="username" />
```
