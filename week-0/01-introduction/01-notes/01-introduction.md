# Foundation : Setting Up IDE And Basics

## What is an IDE ?

- IDE stands for integrated development environment.It is a code editor just like notepad.

- Ex : VSCode , WebStorm , Emacs , Vim etc.

## What are Browsers ? How do they render Websites ?

- Browsers are programs that allows users to interact with other computers by requesting to the server via url.

- Browsers renders HTML , CSS and JavaScript into a web page.

## Goal of a Browser

- allows user to interact with other computers.
- renders html , css and js into a web page.

## Who can create Browsers ?

- Anyone can create browsers.Browser must follow the specifications of HTML , CSS and JavaScript.Specifications means how HTML , CSS and JavaScript renders.

- Ex : firefox , Microsoft edge.

## What purpose do HTML/CSS/JavaScript serve ?

- HTML is used to structure the web page.
- CSS is used to make the web page beautiful.
- JavaScript is used to add interactivity to the web page.

**Note :** HTML , CSS and JavaScript is enough to create almost any website out there.

## How much of this do we actually use in the industry ?

1. html : minimal
2. css : minimal
3. js : heavy

- Facebook , Instagram is written in ReactJs.

- Before 2010 , websites were written in HTML , CSS and JavaScript.But after 2010 , websites are written using frameworks and libraries like ReactJs or Angularjs.
